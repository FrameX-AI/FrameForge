# FrameForge project page

This branch hosts the static [FrameForge project page](https://framex-ai.github.io/FrameForge/). The inference code lives on [main](https://github.com/FrameX-AI/FrameForge/tree/main).

The page and assets were migrated from [Lyne1/FrameForge-page at 0eacf81](https://github.com/Lyne1/FrameForge-page/tree/0eacf81). The canonical URL and social preview metadata were updated for this host. The site needs no build step; the GitHub Pages source is this branch at `/(root)`.

The site adapts the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template), which credits [Nerfies](https://nerfies.github.io/) and is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The original attribution is preserved in the page footer. The research code, model weights, and paper figures are separate from the website template license.
